

## Опис

Цей репозиторій містить матеріали та документацію навчального проєкту.

## Призначення

Проєкт призначений для розробки та документування інформаційної системи відповідно до вимог навчального завдання.

## Тип системи

Web-система.

## Автор

Дарина Кондратюк, група ІПЗ-3/1.

## Структура репозиторію

- `docs/` — технічна документація проєкту;
- `docs/board/` — скріншоти дошки задач та матеріали планування;
- `src/` — вихідний код проєкту;
- `tests/` — автоматизовані тести;
- `.gitignore` — перелік файлів, які не повинні потрапляти до Git;
- `.gitattributes` — налаштування роботи Git з різними типами файлів.

## Документація

Основні документи проєкту знаходяться в каталозі `docs/`.

## Технології

Технологічний стек буде уточнюватися та розширюватися під час подальшої розробки проєкту.
